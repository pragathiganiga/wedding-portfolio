# 💍 Wedding Card Website

A simple and elegant wedding invitation website created using **HTML, CSS, and JavaScript**.  
This website is designed to share wedding details digitally in a modern and responsive way.

## 🌐 Live Demo
👉 https://aksh-sup.netlify.app/

## 📌 Features
- Attractive wedding invitation design
- Responsive layout for mobile and desktop
- Clean UI using CSS
- Interactive behavior using JavaScript
- Fast and lightweight website

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
Wedding-Card-Website/
│── index.html
│── style.css
│── script.js
└── assets/
└── images/

## 🚀 How to Run the Project
1. Download or clone the repository  
2. Open the project folder
3. Open `index.html` in any web browser

## 🎯 Project Objective
The main goal of this project is to practice front-end web development skills and create a digital wedding invitation that can be easily shared with guests.
